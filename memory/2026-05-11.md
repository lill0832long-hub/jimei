### 3. 架构重构方案（重大决策）
**需求升级：**
- 多人并发使用（从单用户桌面应用 → 多用户 Web SaaS）
- UI 更精美

**技术选型：**
- 后端：FastAPI（已有）+ SQLAlchemy async + aiosqlite/asyncpg
- 前端：NiceGUI（已有）+ Tailwind CSS（美化）
- 数据库：SQLite（开发）→ PostgreSQL（生产）
- 认证：JWT + bcrypt（已有）
- 部署：Docker（生产阶段）

**架构分层：**
```
浏览器 → NiceGUI 页面层（+ Tailwind）→ 服务层（认证/校验/缓存）→ SQLAlchemy ORM → aiosqlite/asyncpg → 数据库
```

**迁移计划（6 周）：**
- 第 1 周：SQLAlchemy Model 定义（25 张表）
- 第 2 周：数据库层替换（database/ → app/repository/）
- 第 3 周：服务层重构
- 第 4 周：多用户支持（JWT 认证 + 请求级状态隔离）
- 第 5 周：UI 美化（Tailwind CSS）
- 第 6 周：测试 + Docker 部署配置
