## 关键经验

1. **CSS 类遗漏是静默故障** — HTML 中引用了 CSS 类但样式不存在，不会报错，只会表现为"样式不对"。修复后应建立检查机制：grep auth.py 中的所有 class 引用，反向验证 style.css 中都有定义。

2. **Edit 工具 tab 编码陷阱** — Windows 文件的 tab/space 编码与 Read 输出不一致时，Edit 的 old_string 匹配会静默失败。解决方案：用 Python 脚本通过 Bash 做文件替换，或先 Read 后立即用精确内容 Edit。

3. **版本号多处硬编码** — 版本信息分散在 app.py、settings.py、ui_helpers.py 三个文件中，完全独立。未来应考虑单一来源（如 `__version__.py`），其他文件 import 引用。

4. **WSL 同步路径** — `E:\ClaudeCode\my-project` 通过 `/mnt/e/ClaudeCode/my-project` 映射到 WSL。同步命令：`wsl -e bash -c "cp /mnt/e/.../file /home/administrator/.openclaw/workspace/ai-finance-app/..."`。
